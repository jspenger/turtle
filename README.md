# Turtle

Turtle is a _specification_, _implementation_, and _proof_ (SIP) system for writing software with AI.
It currently supports writing software in RISC-V assembly code with x86 support to be added soon.
The intended workflow is structured around a _specification_ written as a _machine-checkable contract_:

* The human programmer writes a _specification_
* The AI writes an _implementation_
* The AI writes a _machine-checkable proof_ that the implementation satisfies the specification
* The human executes / verifies the machine-checkable proof

Disclaimer: _Turtle is still being developed and should not be used in "the real world" or "production systems"_.

Sponsorship is welcome.

## Why Turtle?

The goal of Turtle is to make it _easy_ to write _good_ specifications.
Specifications are written in the [Coq](https://rocq-prover.org/) language in a [Temporal Logic of Actions](https://en.wikipedia.org/wiki/Temporal_logic_of_actions) (TLA) embedding.
TLA is (in my opinion) the best formalism for writing specifications.
Our main focus is on specifications (including the statement of theorems), whereas most other projects focus on specifications, implementations, and proofs.

## Repository overview

Turtle provides the following subprojects / tools for writing specifications, implementations, and proofs.

* `turtle-tla/`
    * A (shallow) embedding of the [Temporal Logic of Actions](https://en.wikipedia.org/wiki/Temporal_logic_of_actions) (TLA) in [Coq](https://rocq-prover.org/) for writing specifications and proofs
* `turtle-tla-lib/`
    * Various helpers and theorems
* `turtle-compat/sail-riscv/`
    * Compatiblity / connector with the [Sail RISC-V model](https://github.com/riscv/sail-riscv) in Coq for writing implementations and proofs

See the examples for more details.
A good starting point is [example 01](examples/01-turtle-tla-hour-clock/) with an example of TLA specifications and proofs written in `turtle-tla`.
[Example 04](examples/04-turtle-compat-sail-riscv-fibonacci/) is a good starting point for an example with a human-written specification of a Fibonacci procedure, and AI-generated implementation and proofs.

## Proofs

All proofs are on the `x-proof-main` branch and _not_ on the `main` branch; this is to avoid cluttering the repository.
All proofs are generated by Claude Opus 5.5 and Fable 5.2.

## Installation

The recommended way to get started is to build and run the project's [Dockerfile](scripts/docker/Dockerfile) for which you can find instructions in its [Readme](scripts/docker/README.md).
If you instead would like to install the project natively, then follow the instructions as is done in the [Dockerfile](scripts/docker/Dockerfile) to install the dependencies and build the project.

## Etymology

The name `Turtle` comes from the phrase "turtles all the way down" ([Wikipedia](https://en.wikipedia.org/wiki/Turtles_all_the_way_down)).
This project was previously named `Tulip`.
